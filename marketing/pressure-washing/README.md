## Build

Everything is generated by `build.sh` (uses `magick` from ImageMagick 7).
Re-run any time you change a layout:

```sh
bash build.sh
```

The script reads the brand white logo from
`../brand/logo-white/bridgepointe-logo-white-1024.png` (produced by the brand
foundation pass) and writes all 12 graphics to this directory.

## Brand convention (must stay consistent across future graphics)

- **Background:** charcoal `#0f0f0f`
- **Top-left corner of every graphic:** white-knockout BRIDGEPOINTE logo
  (emblem + wordmark + tagline) from `../brand/logo-white/`. Sized at:
  - 200px wide on 1080×1080 / 1080×1350 feed graphics
  - 240px wide on 1080×1920 9:16 covers
  - 130px wide on 1080×540 before/after strip (placed inside bottom brand bar)
- **Top-right corner:** small gold "PRESSURE WASHING" tag (Helvetica Neue,
  22pt feed / 26pt 9:16, kerning 5) with a 3px gold rule directly below it.
  This is the campaign sub-brand identifier.
- **Footer (every graphic):** `(862) 421-8973` in gold + `BRIDGEPOINTEPAINTING.COM`
  in muted grey, kerned 5.
- **Accent color (per graphic):**
  - 01 Launch + 02 Why Hot Water → red `#f87171` for "HOT WATER" / "01-03" numbers
  - 03 Pollen → yellow `#fbbf24`
  - 04 Pricing → gold `#b8956a` (bundles highlighted in gold)
  - 05 Before/After → red `#f87171` BEFORE pill, green `#34d399` AFTER pill
  - 06 Commercial → green `#34d399`
- **9:16 covers** add a thin vertical accent rule (3px wide, color matched to
  graphic accent) running down one side margin to make the format feel
  intentional, not stretched.

## 05 Before/After — replace placeholder photos

The before/after template uses the first two `.jpg` photos found under
`/public/images` as **placeholders** to demonstrate the composition. As soon
as you have real pressure-wash before/afters, swap them in:

- For the 1080×540 horizontal version, pipe through:
  ```sh
  magick \
    \( before.jpg -auto-orient -resize 540x470^ -gravity center -extent 540x470 \) \
    \( after.jpg  -auto-orient -resize 540x470^ -gravity center -extent 540x470 \) \
    +append /tmp/ba-row.jpg
  ```
  Then re-run the overlay block from `build.sh` (BEFORE/AFTER pills + brand bar).

- For the 1080×1920 vertical version, build it as a stack: 320px charcoal
  header, 720px BEFORE photo, 720px AFTER photo, 160px charcoal footer.

The script's auto-discovery picks up the first two images under
`public/images`; once you drop real photos at the top of that tree (or hard-
code paths in `build.sh`), the template will use them on the next run.
